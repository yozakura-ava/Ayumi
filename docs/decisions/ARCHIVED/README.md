# Archived Documentation

These files are historical Paperclip issue specs and completed sprint plans. They've been archived because:
- They describe work that is complete and the actual code lives in `src/forex_bot/`
- They reference early cAlgo/C# planning that was superseded by the Python implementation
- They were initial research/assessments now covered by the canonical status doc

**Do not delete** — they contain useful historical context and design decisions.

## Contents

### sprint-plans/
Sprint 1-3 issue specs (AYUAA-33 through AYUAA-43). All marked "done" in Paperclip. The actual implementations are in `src/forex_bot/backtest/ict_smc/`, `src/forex_bot/config/sessions.py`, etc.

### calgo-planning/
Early cAlgo/C# planning docs (AYUAA-11, 26, 27, 31, 73). The project pivoted to Python with FIX protocol. cBot code still exists in `src/forex_bot/cbot/` but these planning docs are no longer active.

### early-research/
Initial infrastructure assessment (AYUAA-6) and company planning (AYUAA-1). Superseded by canonical status and actual implementation.
